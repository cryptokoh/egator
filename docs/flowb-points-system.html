FlowB Points System

A thoughtful, cross-platform rewards system that respects user attention and encourages organic engagement with the FlowB ecosystem.

Design Document v1.0

Core Philosophy

🌱

Organic Growth

Points reward natural usage patterns. No dark patterns, no FOMO tactics, no aggressive conversion.

🔒

Privacy-First

Anonymous users can accumulate points freely. Registration is optional and gently suggested, never forced.

🌐

Cross-Platform

Earn points everywhere: FlowB chat (Telegram, Discord, OpenClaw), web UI, social shares, and referrals.

⚖️

Balanced Economy

Daily caps prevent inflation. First-time bonuses reward exploration. Streaks reward consistency without punishing absence.

Key distinction: FlowB Points are completely separate from DANZ XP. Different system, different purpose. FlowB Points are platform-level engagement currency across the entire ecosystem.

Notification Philosophy

The points system should feel like a pleasant surprise, never an interruption. Different contexts get different treatment.

Subtle FlowB Chat (DM)

A small footer appended to the normal response. Never a separate message.

[FlowB's normal response to your question] --- +2 pts | 47 total

At milestones, a slightly expanded footer:

[FlowB's normal response] --- +3 pts | 100 total Pathfinder!

Minimal FlowB Chat (Group)

Even more restrained in public contexts. Milestone celebrations DM the user if the platform supports it. Otherwise, a single quiet line.

[FlowB's response to the group] 100 pts - nice!

Gentle Web UI

Micro-awards: Existing toast popup in bottom-right corner (+2 Event explored). Quick, unobtrusive, auto-dismisses in 2 seconds.

Milestones: Thin dismissible banner below the header. Auto-dismisses after 8 seconds or on tap. One line of celebratory text.

Anonymous claim prompt: A bottom-sheet that slides up. Only at milestones 25 and 100. "Maybe later" is the default/prominent button. "Register" is the secondary action. Each prompt shown only once. Never a blocking modal.

Anonymous to Registered Flow

Users can enjoy the platform without signing up. Points accumulate quietly, and registration is gently suggested at key moments.

1
First visit - Anonymous UUID generated, stored in browser. Points start accumulating in localStorage.
↓
2
25 points - Gentle bottom-sheet appears once: "You've been exploring! Register to save your progress." Easily dismissed.
↓
3
100 points - Second (and final) prompt: "100 points earned. Create an account to keep them and unlock referral rewards."
↓
4
Registration - All localStorage points transfer to the backend. One-time sync. Future points go directly to database.
↓
5
Referral unlocked - Registered users get a unique referral code and can earn social points.

After dismissing both prompts, the user is never prompted again. The points badge in the header remains visible as a passive reminder that points exist.

Streak System

Streaks reward consistency but don't punish breaks. Missing a day resets the counter, but accumulated points and milestone progress are never lost.

How Streaks Work

1
Each day's first interaction awards +5 daily login bonus and advances the streak
↓
2
At 3, 7, and 30 consecutive days, bonus points are awarded automatically
↓
3
Missing a day resets the streak counter to 0 (but all earned points remain)
↓

Longest streak is tracked as a personal record

Technical Architecture

Where Points Live

User TypeStorageSync
Anonymous (web) Browser localStorage Transfers to DB on registration
Registered (web) Supabase (via API) Real-time
FlowB chat users Supabase (direct) Real-time

Database Tables

flowb_points_ledger - Append-only audit trail of every point transaction. Columns: user_id, platform, action, points, metadata (JSONB), created_at.

flowb_user_points - Aggregated balance per user+platform. Columns: total_points, referral_code, referred_by, current_streak, longest_streak, last_active_date, first_actions (JSONB), milestone_level.

All tables use the flowb_ prefix for clean portability when migrating away from DANZ Supabase.

New FlowB Actions

ActionDescriptionAuth Required
points Check your FlowB point balance, streak, and milestone Yes (user_id)
referral Get your unique referral link Yes (registered)

Cross-Platform Identity

Points are tracked per user_id + platform pair. A user on Telegram and the same user on Discord have separate point balances. This is intentional for privacy. Future: the DANZ verification bridge can optionally unify identities if the user consents.
